Lightweight and Explainable AI for Detecting Adversarial Attacks on Object Detection in Autonomous Vehicles

Working title. The project studies physical attacks on the camera side of autonomous driving (altered signs, stickers, shadows, reflected or projected light, manipulations that unfold over video frames) and asks whether cheap, explainable consistency checks can flag them without slowing the vehicle down.

Current phase: literature mapping and research design. No experiment has been run yet, so this site reports no results. The design below is a set of hypotheses, not a proven method.

Problem

Autonomous vehicles rely on cameras and AI models to recognize road signs, pedestrians, cars, and obstacles. However, attackers can manipulate visual information using altered signs, stickers, patterns, or lighting to confuse these models. As a result, vehicles may fail to recognize dangerous objects, classify them incorrectly, or detect obstacles that are not actually there. These attacks can become more challenging to detect at night or in poor weather, when visibility is already limited. Existing defenses may struggle with unfamiliar attacks or require significant computing power.

Approach

The plan is to develop a lightweight and explainable AI model that identifies suspicious changes in visual information and object detection results, by analyzing object appearance, shadows, reflections, lighting, and changes across video frames.

Planned contributions

  1. Detect possible adversarial attacks targeting object detection models.
  2. Identify objects that are hidden, missed, or misclassified because of visual manipulation.
  3. Distinguish suspicious visual changes from normal lighting and weather conditions.
  4. Improve detection reliability under nighttime and low-visibility conditions.
  5. Develop a lightweight model suitable for vehicles with limited computing resources.
  6. Explain which visual inconsistencies caused the system to flag a possible attack.
  7. Evaluate detection accuracy, false alarms, processing time, and robustness using public datasets.

Five cue families

1. Object appearance

Viewpoint-aware structural disagreement

Low-cost evidence that an object's geometry and the detector's output disagree, without rebuilding the whole image.

48 papers in the literature map

2. Shadows

Physics-gated temporal shadow evidence

Check whether shadow movement is physically plausible before treating a detector failure as an attack.

45 papers in the literature map

3. Reflections

View-conditioned light consistency

Detect suspicious object responses to changing view and illumination without assuming every reflection is malicious.

45 papers in the literature map

4. Lighting

Global-local exposure and flicker test

Combine local-versus-global illumination residuals with temporal flicker patterns under a fixed compute budget.

42 papers in the literature map

5. Changes across video frames

Bounded causal multi-cue evidence

Lightweight sequential disagreement scoring with measured latency and an explicit insufficient-evidence state.
